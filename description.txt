=========================================
          TochIDE - Ultimate Terminal IDE
=========================================

TochIDE — это легковесная, но мощная среда разработки (IDE), работающая 
непосредственно в терминале (оптимизирована для Termux на Android).

ОСНОВНОЙ ФУНКЦИОНАЛ:

1. ДИНАМИЧЕСКИЙ ИНТЕРФЕЙС:
   - Трехпанельная верстка: Дерево файлов (слева), Редактор (центр), Виджеты (справа).
   - Zen Mode (Ctrl+B): Мгновенное скрытие боковых панелей для расширения области кода.
   - Миникарта (Ctrl+G): Визуальное отображение структуры кода с плавным скроллом.

2. СИСТЕМА ТЕМ:
   - Поддержка горячей смены тем (F1).
   - Подгрузка стилей из папки 'themes/'.
   - Пресеты: Dark, Light, Custom (с поддержкой пользовательской настройки HEX-цветов).

3. РЕДАКТОР КОДА:
   - Многовкладочность (Tabs): Открытие нескольких файлов одновременно.
   - Подсветка синтаксиса: Автоматическое определение языка (Python, JS, C++, и др.).
   - Поиск (Ctrl+F): Мгновенная навигация к найденному тексту в активном окне.

4. ВСТРОЕННЫЙ ТЕРМИНАЛ:
   - Интерактивная командная строка (Ctrl+T) в нижней части экрана.
   - Выполнение системных shell-команд в фоновом режиме (через Subprocess).
   - Вывод логов работы и ошибок в реальном времени.

5. СИСТЕМНЫЙ МОНИТОРИНГ:
   - Ресурсный виджет: Отображение загрузки CPU и RAM в реальном времени.
   - Информационный виджет: Статистика активного файла (размер, дата изменения).

ГОРЯЧИЕ КЛАВИШИ:
- F1         : Смена цветовой темы
- Ctrl + B   : Режим Zen (Скрыть/Показать панели)
- Ctrl + G   : Показать/Скрыть миникарту
- Ctrl + F   : Фокус на поиске
- Ctrl + S   : Сохранить активный файл
- Ctrl + W   : Закрыть текущую вкладку
- Ctrl + T   : Фокус на терминал
- Ctrl + L   : Очистить лог терминала
- Ctrl + Q   : Выход из приложения
